# Little Turtle Planner 🐢 — техническое задание

Полноценное бесплатное мобильное PWA для ежедневных задач и привычек. Русский интерфейс, без регистрации, серверов, платных API и подписок. Данные сохраняются локально между сеансами, после первой загрузки доступна работа без интернета.

## Технологии и архитектура

React, TypeScript, Vite, Tailwind CSS, Lucide React, date-fns, IndexedDB, service worker и manifest. Модульные компоненты, типизированные модели, независимые бизнес-логика и хранилище. Обработка ошибок загрузки/сохранения, семантическая разметка и доступные элементы управления.

## Дизайн

Кремовый фон #F8F3E8, шалфейный #E5EEDC, оливковый #B7C9A8, коралловый #E8A19A, приглушённый зелёный #718A75. Минимализм, мягкие скругления, деликатные тени, воздух, современная типографика. Оригинальный SVG-талисман красноухой черепашки с зелёным панцирем, округлой головой, маленькими лапками, коралловыми полосками у глаз и дружелюбной мордочкой.

## Главный экран

Шапка с названием и талисманом, горизонтальная прокручиваемая лента привычек без искусственного лимита, разделы «Сегодня», «Завтра», «В течение недели», доступ к выполненным задачам. Мобильная адаптация и управление одной рукой.

## Привычки

Создание, редактирование, удаление: название, встроенная иконка, цвет круга, повторение каждый день / выбранные дни недели / каждые N дней с исходной датой. Нажатие круга отмечает текущую локальную дату, повторное отменяет. Невыполненные перед выполненными, внутри групп исходный пользовательский порядок. Подробности открываются отдельной кнопкой. Незапланированные привычки не считаются пропусками.
Проверка даты при открытии, возврате из фона и смене дня; история сохраняется навсегда. Использовать локальные даты без ошибок UTC и часовых поясов.
Подробная карточка содержит «Отслеживание выполнения привычки»: месячный календарь понедельник–воскресенье, переключение месяцев, выделение выполнений, отличие незапланированных дней и будущих от пропусков, число выполнений в месяце.

## Задачи

Создание, редактирование, удаление, название и приоритет 1 (высокий, коралловый), 2 (средний, пастельно-жёлтый), 3 (низкий, светло-зелёный). Добавление в каждом разделе. Сегодня и завтра имеют календарные даты. Недельные задачи имеют срок до воскресенья текущей недели; модель допускает конкретный день.
Выполнение флажком, зачёркивание, перенос в выполненные, сохранение даты завершения и отмена. Просроченные незавершённые задачи показывать сегодня, сохраняя исходный срок, название и приоритет, без дубликатов, в том числе после нескольких дней отсутствия.

## Поздравление

После выполнения привычки снизу плавно появляется счастливая черепашка, моргает/машет лапкой, случайная фраза: «Маленький шаг, большой успех!», «Черепашка тобой гордится!», «Ещё одна победа!», «Ты сегодня молодец!», «Тихонько, но вперёд!». Исчезновение через 2–3 секунды, не блокировать действия, учитывать prefers-reduced-motion, использовать CSS/SVG без тяжёлых библиотек.

## Сохранение и PWA

IndexedDB хранит все задачи, приоритеты, статусы, даты создания/завершения, привычки, расписания, иконки, цвета, порядок и историю. Экспорт JSON и импорт с проверкой структуры. Ошибки не должны приводить к тихой потере данных.
Иконка черепашки, установка Android/iPhone поддерживаемыми браузерами, standalone, офлайн, безопасные обновления без потери IndexedDB. Бесплатный статический хостинг.

## Этапы

1. Структура, Tailwind, PWA, тема.
2. Главный экран, лента, разделы.
3. CRUD задач, выполнение и перенос.
4. CRUD привычек, расписания, сортировка.
5. Карточки и календарь.
6. SVG и поздравление.
7. Хранилище, резервные копии, офлайн.
8. Автотесты дат, повторений, переноса, истории; сборка и документация публикации.

## Готовность

Неограниченные привычки с настройками, отметками, сортировкой и календарём; задачи трёх разделов с приоритетами, выполнением, отменой и переносом; данные после перезапуска; офлайн, экспорт/восстановление и установка PWA. Приложение для ежедневного использования, не демонстрационный макет.
