# Разработка Little Turtle Planner

Согласованные требования: [PROJECT_SPEC.md](PROJECT_SPEC.md).
Интерфейс на русском. Не добавлять серверы, регистрацию, платные сервисы или телеметрию.
Хранить локальные даты как yyyy-MM-dd, не переводить календарные дни через UTC.
Разделять UI, чистую бизнес-логику и IndexedDB. Не стирать историю при смене дня.
Изменения схемы хранения должны сохранять существующие данные. Проверять импорт до записи.
Перед завершением запускать npm test и npm run build. Поддерживать доступность и reduced-motion.
Использовать текущую изолированную копию репозитория, не создавать worktree без просьбы пользователя.
